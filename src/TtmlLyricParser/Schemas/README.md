# Bundled TTML2 schemas

These 22 XSD files are copied without modifications from the W3C TTML2 Recommendation dated 2018-11-08:

https://www.w3.org/TR/2018/REC-ttml2-20181108/xsd/schema.zip

Specification and schema notes:

https://www.w3.org/TR/2018/REC-ttml2-20181108/#ttml-schema-xsd

Copyright © 2018 W3C (MIT, ERCIM, Keio, Beihang).
W3C licensing information: https://www.w3.org/copyright/software-license/

The library embeds the XSD files and resolves their imports/includes exclusively from its own assembly. The XSDs are not sufficient for full TTML2 conformance. Foreign namespace content is retained in the output source tree while a pruned view is used for core validation.
